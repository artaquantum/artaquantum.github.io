2026-09-23meta

Short daily notes on quantum information and computation: a result worked through, a derivation checked, a computation that surprised me.

Math is written in LaTeX. Inline, the Bell state \(|\Phi^+\rangle = (|00\rangle + |11\rangle)/\sqrt{2}\); on its own line, its reduced state on either qubit is maximally mixed:

\[ \rho_A = \operatorname{Tr}_B |\Phi^+\rangle\langle\Phi^+| = \tfrac{1}{2}\,I. \]

Code is shown with its language named on the fence:

bell = {1, 0, 0, 1}/Sqrt[2];
